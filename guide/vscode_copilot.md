# 🧑‍💻 VS Code con GitHub Copilot

Serve nel modulo 11, per vedere un **agente** che scrive codice da solo. Non sostituisce RStudio: è un'esperienza di una lezione.

1. Crea un account su [github.com](https://github.com) con la mail universitaria (serve anche per la verifica studenti).
2. Installa [Visual Studio Code](https://code.visualstudio.com).
3. In VS Code, **Estensioni** (icona a sinistra) → cerca *GitHub Copilot* → Installa → accedi con l'account GitHub. Il piano **Copilot Free** basta per il corso; se le iscrizioni a *Copilot Student* sono aperte, attivalo dal [GitHub Student Developer Pack](https://education.github.com/pack).
4. Apri la chat di Copilot (icona in alto a destra) e scegli la modalità **Agent**.
5. Apri una cartella vuota, chiedi all'agente di risolvere un lab del corso incollando la specifica dalla pagina del lab, e poi **verifica il suo codice nella pagina del lab**: i casi nascosti valgono anche per lui.
